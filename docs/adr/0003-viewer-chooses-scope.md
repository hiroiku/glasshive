# ADR 0003 — 観る範囲をやめ、観る人に渡す

- 状態: 有効
- 置き換えるもの: 起動した場所で観測の範囲が決まる作り(`[path]` と `--global`)

## 背景

前の作りは、起動した場所で何が観えるかが変わった。git の巣の中で起動すればその巣だけ、
`--global` を付ければ家じゅう。これには 3 つの困りごとがあった。

- **同じ道具が、開いた窓ごとに違うものを見せる。** どこから起動したかを覚えていないと、
  一覧に出ていない巣が「無い」のか「範囲の外」なのか読めない
- **範囲が観測と見せ方の両方を兼ねていた。** 絞りたいのはたいてい表示のほうなのに、
  観測そのものが狭まるので、隣の巣で何か起きても気づけない
- **範囲の判定が、外から渡された絶対パスに依っていた。** 口(`?project=`)がそのまま
  ファイルの場所を受け取るので、`<img src="http://127.0.0.1:4483/api/git?project=/etc">`
  のような形で外の頁から引ける穴になっていた

## 決めたこと

**観測の範囲という考えをやめる。** `~/.claude/projects` の下でエージェントが動いた巣は、
どこから起動しても全部が一覧に出る。`[path]` と `--global` は無くした。

**タブに並べるものは観る人が選ぶ。** 一覧の行の左端で留め、タブ行で並べ替え、× で外す。
選びは覚え書きに残る([ADR 0001](0001-read-only.md) の例外)。

- 選びは**見せ方の話であって、観測には一切効かない**。設定ファイルが観測の範囲を
  広げたり狭めたりする道は作らない
- 観測から消えた巣も、留めた印は残す。作業場所は消えて後で戻ることがある。
  **選びが観測を発明しない**ように、留めた印に在っても観測に無ければタブには出さない
- 何も留めていなければ Overview だけ。勝手に留めない、仮のタブも作らない
- 留めていない巣を観ているあいだは、行の末尾に斜体で今いる場所を出す。
  出さないと「自分がどこに居るか」がタブ行から消える

**口は絶対パスを受け取らない。** `?project=` が取るのは観測済みの巣の id(併合した組の
代表 slug。辞書順で最小なので毎回同じ)だけで、サーバーは自分の観測から場所を引く。
引けない id は 404。**道を遡るという攻撃面がそのまま消える。**

会話の頁送りだけは在り処(`?file=`)を残したが、前方一致ではなく
**観測した集合に属するか**で見る。繋ぎと競合の隙間が塞がる。

## Overview の作り直し

範囲をやめたので、一覧が最初の画面になった。あわせて次を変えた。

- **1 度の走査で一覧と 24 時間ぶんの消費を返す。** 前は巣ごとに口を叩き、その度に全部を走査していた
  (100 の巣で 100 回)
- **既定の並びを「人待ち > 稼働 > 待機 > 最終活動の新しい順」にした。** 前は消費の多い順で、
  昨日ぶん回した巣が居座り、いま返事を待っている巣が沈んでいた。この道具は消費を眺めるためのものではない
- 探し(名前と場所)、状態の札(入力待ち / 稼働中 / タブ)、期間の札(24h / 7d / 30d / 全期間、既定 30 日)
- 同じ呼び名の巣が複数あるときだけ、名前の右に一つ上の名前を薄く添える

## 代償

- 家じゅうの巣が並ぶので、一覧が長い。期間と探しで畳む
- 前の作りの `?project=<絶対パス>` を叩いていたものは動かない。手元だけの道具なので互換は取らない
