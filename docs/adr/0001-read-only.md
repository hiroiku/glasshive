# ADR 0001 — 正本から導き、何も書かない

- 状態: 有効(2026-08 に「覚え書き」の例外を追記)

## 背景

観るための道具が観る対象に触ると、観測が汚れる。エージェントに合図を送る、印を置く、
問い合わせる — どれも「観ていなければ起きなかったこと」を盤面に足す。

そして、この種の道具でいちばん質の悪い嘘は 2 つある。

- **見に行けなかったのに「空」を返す。** 権限が無い・道具が入っていない・列挙に失敗した、を
  すべて空配列に潰すと、観る人には「何も起きていない」としか見えない
- **空だったのに「エラー」を返す。** 台帳を使っていない巣、まだコミットの無い記録を
  失敗として隠すと、観られるはずの盤面が消える

## 決めたこと

**観測元へは何も書かない。何にも問い合わせない。** 読むのは次の 3 つだけである。

| 正本 | 場所 |
| --- | --- |
| 会話の記録 | `~/.claude/projects/**/*.jsonl` |
| 課題の台帳 | `<巣>/.beads/issues.jsonl` |
| 記録の様子 | `git` を読み取りの形でだけ起こす |

そして**観測の結果は値で表し、投げるのはプログラムの誤りだけにする。**

```
Observation<T> = 観えた(値)
               | 無い(no-source / empty / out-of-window)
               | 観に行けなかった(誤り)
```

- 「無い」と「観に行けなかった」を互いに丸めない。errno を見分けられるのは errno が見える場所だけなので、
  そこで分ける(`ENOENT` は無い、`EACCES` は観に行けなかった)
- 欄の単位でも同じ。`tokens: number | null` には `tokens_state` を、
  `intervals_complete` には `intervals_state` を添える
- 外へ出すときも分ける。台帳が無い・記録が無いは **200 の「無い」**、
  観に行けなかったは **503**。無いものを 404 にすると、観られるはずの画面が消える

## 例外 — 覚え書き

タブに何を並べるかを観る人が選ぶ([ADR 0003](0003-viewer-chooses-scope.md))ので、
選んだことを覚えておく場所が要る。**この道具が書くのはここだけである。**

- 置き場は `$XDG_CONFIG_HOME/glasshive/preferences.json`(無ければ `~/.config/glasshive/`)
- 置く前に、解いた先が**読みに行く先**の下でないことを確かめ、そうであれば断る。
  読みに行く先は `~/.claude`・正本の置き場・`<巣>/.beads`・`<巣>/.git` の 4 つ。
  **確かめは呼ぶ側から外せない場所に焼き込む** — 材料を渡す側が決められると、
  渡し忘れがそのまま穴になる
- **断つのは読む先であって、巣そのものではない。** 家(`~`)を作業場所にして
  エージェントを走らせた履歴があれば家そのものが巣になり、巣ごと断つと既定の置き場
  (`~/.config/glasshive`)にも置けず、留めることが一切できなくなる。読む先へは書かないという
  芯は、上の 4 つで足りる
- 繋ぎ(symlink)で観測元へ向けられていないかも見る。字だけの見比べでは擦り抜ける
- 一時ファイル + rename で置き換える。途中で落ちても壊れた覚え書きが残らない
- 読めなくても観測は止まらない。既定に倒れて動き続ける

**覚え書きは観測に一切効かない。** 何を観測するかと、何をタブに並べるかは別のもので、
設定ファイルが観測の範囲を広げる道は作らない。
