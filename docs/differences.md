# 意図して変えたこと

旧実装(依存ゼロの Node ESM サーバー + 別ビルドの React SPA)から移すにあたって、
**わざと違う振る舞いにしたもの**をここに並べる。

ここに挙がっていない差は退行である。移植の間だけ置いた突き合わせの検めは、
この一覧に載っているものだけを落として旧実装と比べ、fixture でも実データでも緑だった。

## 観る範囲

| | 旧 | 新 |
| --- | --- | --- |
| 起動 | 起動した場所で観測の範囲が決まる(`[path]` / `--global`) | 範囲そのものが無い。`~/.claude/projects` の下は全部出る |
| CLI | `[path]` `--global` `--port` `--active-threshold` `--no-open` | `--port` `--active-threshold` `--no-open` `--config-dir`。読めない指定は断って止まる |
| `/api/tree` | `scope` 欄がある | 無い |
| タブ | 起動の範囲に従う | 観る人が一覧から留める。並べ替え・× で外す |
| 書き込み | 何も書かない | 覚え書き 1 つだけ(`$XDG_CONFIG_HOME/glasshive/preferences.json`) |

→ [ADR 0003](adr/0003-viewer-chooses-scope.md)

## 「無い」と「観に行けなかった」

旧はここを全面的に潰していた。**潰さないことが、この移し替えのいちばんの動機**である。

| ところ | 旧 | 新 |
| --- | --- | --- |
| プロセスの列挙に失敗 | 空配列 → **待機のセッションが全部「終了」に見える** | `unobservable` を運び、画面が「見分けが付きません」と言う |
| `git` が入っていない | すべてのリポジトリが 404(=「リポジトリではない」) | 503 `git.not_installed` |
| リポジトリでない場所 | 404 | **200** + `state: absent, reason: no-source` |
| 台帳が無い | 404 | **200** + `state: absent`(`bd` の案内を出す) |
| 権限が無くて読めない | 空の Buffer → 「空のセッション」に見える | `unobservable` |
| 窓の外の消費と stat の失敗 | どちらも `null` | `tokens_state` で分ける |
| 形の違う指し(`--upload-pack=…`) | 404 | **400** `git.invalid_revision` |

→ [ADR 0001](adr/0001-read-only.md)

## 塞いだ穴

| | 旧 | 新 |
| --- | --- | --- |
| `?project=` | 任意の絶対パスをそのまま使う。外の頁から `<img src>` で引ける | 観測済みの巣の id のみ。引けなければ 404 |
| `?file=` | 前方一致で許す | 観測した集合に属するかで見る(繋ぎと競合の隙間が塞がる) |
| `?rev=` | 素通し | 形を検め、`git` へ渡す前に `--end-of-options` を挟む |
| `Host` | 一切見ない(DNS リバインディングが通る) | 起動口 / Vite / Start の 3 層で見て 403 |
| 覚え書き | (書かない) | 置く前に、読みに行く先(`~/.claude`・正本の置き場・`<巣>/.beads`・`<巣>/.git`)の下でないことを確かめ、そうであれば断る |

## 直した不具合

- **「もっと前」が動かないことがある。** 正本の 1 行は長く、一歩ぶん(256KiB)より長い行に当たると
  その一歩には行の頭が 1 つも無く、頁が空で返る。旧は読み始めた位置を窓の始まりとして覚えるので、
  以後そのボタンは同じ範囲を永久に読み直していた。新は**頼んだ位置**を覚え、読めるまで遡る
- **場所の書き表し方が揺れているとプロセスを取りこぼす。** 旧は正本の生の字とプロセスの実パスを
  そのまま比べていた。近道(firmlink)の張られた機械では帰属が外れ、待っているセッションが
  終わったものに見えた。新は両辺を同じ形に均してから配る
- **一覧が巣の数だけ走査を起こす。** 旧は巣ごとに口を叩き、その度に全部を走査していた
  (100 の巣で 100 回)。新は 1 度の走査で一覧と 24 時間ぶんの消費を返す
- **戻る印が効かない。** 旧は履歴を差し替えるだけだった。新は道を持つので戻れる
- **記録の画面の Ahead 欄が狭い。** 旧から受け継いだ 48px では `+11 −627` が省略記号に潰れ、
  どれだけ本流から遅れているかが読めなかった。96px に広げた(行ごとに別の grid なので
  `max-content` では列が揃わない)

## 変えた見せ方

- **一覧の既定の並び**を「消費の多い順」から「人待ち > 稼働 > 待機 > 最終活動の新しい順」へ。
  昨日ぶん回した巣が居座り、いま返事を待っている巣が沈むのは、この道具の用事に反する
- **期間の札**(24h / 7d / 30d / 全期間、既定 30 日)を足した。範囲をやめたぶん一覧が長い
- **同じ呼び名の巣**が複数あるときだけ、名前の右に一つ上の名前を薄く添える
- **窓の在り処が URL に載る。** 貼れば相手の画面でも同じ会話・課題・指しが開く
- **`⌘1..9` でタブを移り、`⌘⇧←→` で動かせる**(Apple の盤でなければ `Ctrl`)
- **鍵盤だけで観られる。** 旧は行も札も摘みも `span` に押しどころを持っていて、焦点が当たらなかった。
  新は Tab で辿れ、Enter / Space で開き、いま何処に居るかが枠で出る。帯の摘みは矢印で動かせる
- **書体を Noto Sans 系に統一し、配りものに同梱した。** 旧は `SF Mono` / `Hiragino Sans` /
  `ui-monospace` を名前で指すだけだったので、機械ごとに字面も詰め方も違った。地の文は
  Noto Sans JP、桁を揃える所は Noto Sans Mono。字面の一族(unicode-range)で分けてあるので、
  ブラウザーが取るのは出す字に要る分だけ(実測 977KB)。地の文が等幅でなくなったぶん、
  巣の名前や題は読みやすく、数字・SHA・id の列は等幅のまま揃う
- **会話の窓を詰めた。** 畳んだ行は 11px、話した中身は 10px(旧はどちらも 12px)。
  見出しは `em` で本文から決まるので、本文の大きさを変えれば見出しも一緒に動く
- **台帳の一覧に出る `merge-ready` の札が紫になった。** 同じ名前の決まりが 2 つあり、
  後に書かれた枝側の緑が両方を塗っていた。場所で括って order に依らない形にしたので、
  台帳は台帳の色(紫)、枝は枝の色(緑)になる

## 決め直したところ

- **代表 slug は辞書順で最小のものにする。** 旧はディレクトリを読んだ順に依っていたので、
  同じ観測が二度と再現しなかった
- **`started` は正本の字をそのまま持つ**(ここは**わざと変えなかった**)。時刻の型に潰すと
  正本に書かれていた字が失われる。`last_activity` と `generated_at` は mtime 由来の数なので、
  見せ方の側で整える
- **頭と末尾の二度読みをやめた。** 旧は 128KB 未満のファイルを 2 回走査していた。
  先勝ち / 後勝ち / 集合のどれも結果は変わらないので 1 回で済ませる。頭 → 末尾の順は保つ
- **`<synthetic>` を外す決まりを 1 か所に集めた。** 旧は 4 か所に散っていた
- **URL は `/projects/$slug/{view}`。** 旧 `/{slug}/{view}` からの互換は取らない
